Supported Voice Commands Cheat-Sheet

  • "Add task [description] at [time]" — Create a new task (e.g., "Add task study Python at 7 PM")
  • "Mark [task name] task as completed" — Mark task complete (e.g., "Mark Python task as completed")
  • "Show today's tasks" — Display today's schedule
  • "Show pending tasks" — Filter pending tasks
  • "Delete my [task name] task" — Delete specific task (e.g., "Delete my project task")
